# 💰 Expense Tracker

A simple Expense Tracker web application built using HTML, CSS, and JavaScript.

## Features

- Add Income
- Add Expenses
- Automatic Balance Calculation
- Transaction History
- Delete Transactions
- Local Storage Support

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Overview

This Expense Tracker helps users manage their daily finances by recording income and expenses. The application automatically calculates the available balance and stores transaction data using browser local storage.

## How to Run

1. Download or clone the repository.
2. Open index.html in your browser.
3. Add income and expense transactions.
4. Track your balance.
